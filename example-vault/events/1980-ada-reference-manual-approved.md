# 1980 — The Ada Reference Manual Is Approved

The Ada reference manual was approved on 10 December 1980, Ada Lovelace's birthday, and the MIL-STD-1815 designation honored her birth year.[^ada-language-history]

It commemorated [Ada Lovelace](../people/ada-lovelace.md "{type: commemorates, role: \"namesake\"}") through the [Ada programming language](../work/ada-programming-language.md "{type: concerns}").

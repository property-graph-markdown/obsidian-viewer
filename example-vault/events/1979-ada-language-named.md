# 1979 — The Ada Programming Language Is Named

In May 1979, the selected Green language proposal, designed by Jean Ichbiah's team, was named Ada in honor of Ada Lovelace.[^ada-language-history]

It commemorated [Ada Lovelace](../people/ada-lovelace.md "{type: commemorates, role: \"namesake\"}") through the [Ada programming language](../work/ada-programming-language.md "{type: concerns}").

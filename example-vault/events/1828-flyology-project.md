# 1828 — Ada Develops the Flyology Project

In 1828, twelve-year-old Ada investigated wing materials, bird anatomy, and the possible use of steam in flight, and planned a book called *Flyology*.[^ada-childhood]

The project was undertaken by Ada Lovelace.

# 1844 — Ada Explores a Mathematical Model of the Nervous System

In 1844, Ada discussed a possible mathematical model for the relation between brain, thought, nerves, and feeling, and visited Andrew Crosse to learn about electrical experiments.[^ada-work]

It involved Ada Lovelace and the electrical experimenter Andrew Crosse.

# 1843 — Note G Presents the Bernoulli Procedure

In 1843, Note G presented a detailed procedure for calculating Bernoulli numbers with the proposed Analytical Engine. It is often called the first published computer program.[^ada-program]

The procedure emerged from work involving Ada Lovelace and Charles Babbage. Babbage later said that he supplied the formulas, while Ada converted them into a step-by-step table and detected an error.[^note-g-overview]

The publication event resulted in the concrete artifact [Note G](../work/note-g.md "{type: resulted_in}"), which belongs to the [Menabrea translation and Notes A–G](../work/menabrea-translation-and-notes.md "{type: concerns, context: \"containing publication\"}") and concerns the [Analytical Engine](../work/analytical-engine.md "{type: concerns}").
